# Luyện phát âm · Pronunciation Focus

A free static website for Vietnamese learners of English. It indexes a curated list of YouTube pronunciation channels and tags each lesson by the sound it teaches (final consonants, -s/-ed endings, /θ ð/, intonation and more). Learners get a distraction-reduced player with A–B looping and speed control, shadow-and-record practice that stays on the device, and progress tracking.

**Live site:** https://trungnv184.github.io/pronunciation-focus/

## Features

- **Browse by sound:** filter by tag group (AND across groups, OR within one), channel, duration and Shorts, with diacritic-insensitive search ("am cuoi" finds "âm cuối"). Filters live in the URL, so a filtered view can be shared.
- **Focus player:** A–B loop, ±1 s nudges, playback speed, keyboard shortcuts (Space, A, B, L, `[`, `]`), and our own end screen with no autoplay.
- **Shadow & record:** listen to the segment, record yourself (3-2-1 countdown), then compare. Recordings stay in IndexedDB on the device, with the last 3 kept per segment.
- **Progress:** started/done per video, daily streak, per-sound progress bars, a "Continue" list and a suggested next group. Export/import as JSON.

## Setup

Requires Node 22 and npm 10.

```bash
npm install
npm run dev        # dev server at http://localhost:5173
npm test           # unit + component tests (Vitest, jsdom)
npm run typecheck  # tsc -b (app + scripts)
npm run validate   # validates data files + 30-day freshness of API data
npm run build      # production build in dist/
```

To preview the production build under the Pages sub-path:

```bash
rm -rf /tmp/pf && mkdir -p /tmp/pf && cp -r dist /tmp/pf/pronunciation-focus && npx serve /tmp/pf -l 4173
# open http://localhost:4173/pronunciation-focus/
```

Deploys are automatic: every push to `main` runs CI (`.github/workflows/ci.yml`) and publishes `dist/` to the `gh-pages` branch (`deploy.yml`).

## How to add a channel

1. Find the channel's `@handle` (shown on its YouTube page).
2. Add an entry to `data/channels.json`:
   ```json
   { "handle": "@example", "title": "Example Channel", "lang": "en", "allPronunciation": false, "note": "why it's here" }
   ```
   Set `allPronunciation: true` only if *every* upload is a pronunciation lesson. Otherwise the keyword filter decides which uploads to keep.
3. Run `npm run validate`, open a PR, and once it's merged run **Actions → Refresh video data → Run workflow**.
4. Removing a channel lowers the video count. If it drops by more than 30%, the refresh refuses to overwrite the index; run the ingest once with `--allow-drop`, either locally or by temporarily adding the flag to the workflow.

## How to fix a tag (overrides)

Tagging is rule-based: keywords in `src/data/taxonomy.ts`, applied by `src/data/tagger.ts`. To correct individual videos, edit `data/overrides.json`:

```json
{
  "include": ["<videoId>"],                 // keep a video the filter missed
  "exclude": ["<videoId>"],                 // drop a video (wins over everything)
  "addTags": { "<videoId>": ["schwa"] },    // add tags
  "removeTags": { "<videoId>": ["r-l"] }    // remove wrong tags
}
```

Tag IDs are listed in `TAG_IDS` in `src/data/taxonomy.ts`. Run `npm run validate`, merge, then run the refresh workflow. To fix a whole class of mistakes, adjust the keywords and add a case to `src/data/tagger.test.ts`.

## How to rotate the YouTube API key

1. In Google Cloud Console → APIs & Services → Credentials, create a new API key and restrict it to **YouTube Data API v3**.
2. In GitHub → Settings → Secrets and variables → Actions, update `YT_API_KEY` (or run `gh secret set YT_API_KEY`).
3. Run **Refresh video data** by hand to confirm it works, then delete the old key in Google Cloud.

The key is never committed, logged, or shipped to the browser. The ingest sends it only in the `X-Goog-Api-Key` header, from CI.

## Data refresh schedule

`public/data/videos.json` is generated by `scripts/ingest.ts` from the YouTube Data API v3. It reads the channel list in `data/channels.json` and the manual fixes in `data/overrides.json`.

- **Freshness:** the YouTube API Services policy requires stored API data to be refreshed at least every 30 days. `npm run validate` fails when `generatedAt` is older than that, so a stalled refresh turns CI and deploys red.
- **Schedule:** the `Refresh video data` workflow (`.github/workflows/refresh-data.yml`) runs every Monday at 02:00 UTC (09:00 in Vietnam), and you can also run it from the Actions tab. When the index changes, it commits to `main` and calls the deploy workflow.
- **API key:** stored only as the repository secret `YT_API_KEY`. It is sent in the `X-Goog-Api-Key` header and never written to the repo, the logs or the site bundle.
- **Safety:** if a channel handle is missing, the API fails or runs out of quota, any channel ends up with 0 videos, or the total drops by more than 30%, the run fails and the old file stays as it is. Use `--allow-drop` when you remove a channel on purpose.
- **Local run:** `read -s YT_API_KEY && export YT_API_KEY && npm run ingest -- --dry-run; unset YT_API_KEY`. To run offline against the recorded fixtures, use `npm run ingest -- --fixture scripts/__fixtures__ --out /tmp/videos.json`. With the default channel list, that fails on purpose: the fixture file has no entries for those handles.
- **Branch protection:** the workflow pushes straight to `main` as `github-actions[bot]`. If you add branch protection, allow that bot to push without a PR.
- **Notifications:** GitHub emails the repo owner when a scheduled run fails. Keep that notification on.
- **60-day pause:** GitHub disables scheduled workflows in public repos after 60 days without any repo activity. If that happens, re-enable "Refresh video data" from the Actions tab.

## Privacy

- No accounts, no analytics, no ads, no backend.
- Recordings are stored only in the learner's browser (IndexedDB) and are never uploaded. Progress is stored in `localStorage`.
- Videos are embedded with the YouTube IFrame API, so YouTube/Google may set cookies under their own policies.
- The site uses YouTube API Services. See the About page for the YouTube Terms of Service and Google Privacy Policy links.
