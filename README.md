# Luyện phát âm · Pronunciation Focus

A static website that indexes a curated list of YouTube pronunciation channels, tags each lesson by the sound it teaches, and gives Vietnamese learners of English a focused player with A–B looping, shadow-and-record practice, and progress tracking.

Live site: https://trungnv184.github.io/pronunciation-focus/

## Run locally

```bash
npm install
npm run dev        # dev server
npm test           # unit + component tests
npm run typecheck
npm run build      # production build in dist/
```
